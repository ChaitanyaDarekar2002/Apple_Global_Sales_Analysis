# 🍎 Apple Global Sales Data Analysis

## 📌 Project Overview

This project analyzes Apple's global sales data using **Python** for data cleaning, exploratory data analysis (EDA), feature engineering, and visualization, followed by **Power BI** for building an interactive business dashboard. The goal is to uncover sales trends, customer behavior, product performance, and key business insights that support data-driven decision-making.

---

## 🎯 Project Objectives

* Clean and prepare raw sales data.
* Perform exploratory data analysis (EDA).
* Analyze product and regional sales performance.
* Identify revenue trends and customer patterns.
* Build an interactive Power BI dashboard for business reporting.
